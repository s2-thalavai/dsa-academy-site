Data structures

How data is laid out in memory, and what that layout makes cheap or expensive.

  • Arrays

    Contiguous memory, O(1) indexing, 2D layouts, dynamic resizing and strings.

    Used by Two pointers, Sliding window, Prefix sum, Cyclic sort and 7 more.

  • Linked lists

    Nodes scattered in memory joined by pointers; singly, doubly and circular.

    Used by Fast and slow pointers, In-place list reversal, K-way merge, Data structure design.

  • Stacks

    Last in, first out. The call stack, recursion and expression evaluation.

    Used by Monotonic stack, Graph BFS and DFS.

  • Queues

    First in, first out. Circular buffers, deques and priority queues.

    Used by Monotonic deque, Tree BFS, Graph BFS and DFS.

  • Hash tables

    Hash functions, buckets, collisions, load factor and resizing.

    Used by Sliding window, Prefix sum, Hashing, Top K elements and 1 more.

  • Trees

    Binary trees, BSTs, balanced trees, traversals, segment and Fenwick trees.

    Used by Tree DFS, Tree BFS.

  • Heaps

    A tree stored in an array. Sift up, sift down and O(n) heapify.

    Used by Top K elements, Two heaps, K-way merge, Shortest path and 2 more.

  • Graphs

    Adjacency lists and matrices, grids as graphs, DAGs.

    Used by Graph BFS and DFS, Topological sort, Union-Find, Shortest path and 1 more.

  • Trie Advanced

    A tree of characters for fast prefix lookups.

    Used by Trie.

  • Disjoint set (Union-Find) Advanced

    Track groups that merge, with path compression and union by rank.

    Used by Union-Find.
