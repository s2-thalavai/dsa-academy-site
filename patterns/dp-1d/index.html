1D dynamic programming

One-dimensional DP problems have a single index of progress: a step, a house, a position in a string. The answer at i depends on a few earlier answers, so you fill a row left to right and often keep only the last two values.

Coding pattern

Picture it. Climbing a staircase where each step has a price. The cheapest way to stand on step i is the cheaper of arriving from step i − 1 or step i − 2, plus the price of step i. You never need to remember more than the last two steps.

Recognise it

  • A sequence (array or string) and a question about the best or number of ways to reach the end.
  • Each decision looks back a fixed number of steps: take or skip this house, decode one or two digits.
  • "Can this string be split into dictionary words?" (each position looks back at word-sized steps).

The template

dp[0..base] = base cases
for i from base + 1 to n:
    dp[i] = combine(dp[i − 1], dp[i − 2], …)     ← the last few states only
return dp[n]
(keep two variables instead of the array when only dp[i − 1] and dp[i − 2] are read)

How it works

State the meaning of dp[i] in words before writing the recurrence:

  • Min cost climbing stairs: dp[i] = cheapest cost to stand on step i. dp[i] = cost[i] + min(dp[i − 1], dp[i − 2]).
  • House robber: best haul from the first i houses. Either skip house i (dp[i − 1]) or rob it (dp[i − 2] + money[i]). In a circle, the first and last houses touch, so run the line version twice: once without the last house, once without the first.
  • Decode ways: ways to decode the first i characters. Add dp[i − 1] if the last digit is 1–9, and dp[i − 2] if the last two digits form 10–26.
  • Word break: whether the first i characters split into words. True if some word ends at i and dp[i − len(word)] is true.

Cost of each operation

OperationTimeWhy
Climbing stairs, house robber, decode waysO(n) time, O(1) spacen states, constant work each, two rolling variables.
Word breakO(n × W × L)For each end, try each dictionary word of length L (or each split point with a hash set: O(n²)).

Code

The first three keep only two rolling values. Word break needs the whole row because it looks back by word lengths.

Common mistakes

  • In decode ways, treating "0" as a valid single digit, or "06" as a valid pair.
  • In circular house robber, forgetting the single-house case.
  • Overwriting the rolling variables in the wrong order, so the new value reads itself.
