Coding patterns

Thirty-one problem shapes that cover most interview questions. Each pattern links to the structures and techniques it builds on.

  • Two pointers

    Two indices walk the data toward each other or in step.

    Builds on Arrays.

    Solved: Two Sum II, sorted input

  • Sliding window

    Grow and shrink a contiguous range instead of rescanning it.

    Builds on Arrays, Hash tables.

    Used by Monotonic deque.

  • Prefix sum

    Precompute running totals so any range sum is one subtraction.

    Builds on Arrays, Hash tables.

  • Hashing

    Trade memory for O(1) lookups of what you've already seen.

    Builds on Hash tables.

  • Cyclic sort

    Place each number 1..n at its own index in one pass.

    Builds on Arrays.

  • Merge intervals

    Sort by start, then merge or count overlaps.

    Builds on Arrays, Sorting.

  • Kadane's algorithm

    Best subarray ending here, carried forward in O(1) space.

    Builds on Arrays, Dynamic programming.

  • Fast and slow pointers

    Two speeds detect cycles and find middles.

    Builds on Linked lists.

  • In-place list reversal

    Reverse links in place with three pointers.

    Builds on Linked lists.

  • Monotonic stack

    Keep a sorted stack to find the next greater or smaller element.

    Builds on Stacks, Arrays.

  • Monotonic deque

    Window maximum or minimum in O(n).

    Builds on Queues, Sliding window.

  • Modified binary search

    Binary search on rotated arrays, boundaries and answers.

    Builds on Arrays, Searching.

  • Top K elements

    A size-K heap keeps the best K seen so far.

    Builds on Heaps, Hash tables.

  • Two heaps

    A max-heap and a min-heap split the data at the median.

    Builds on Heaps.

  • K-way merge

    Merge K sorted inputs using a heap of their heads.

    Builds on Heaps, Linked lists.

  • Tree DFS

    Pre, in and post order, and passing state down or up.

    Builds on Trees, Recursion.

  • Tree BFS

    Level by level with a queue.

    Builds on Trees, Queues.

  • Graph BFS and DFS

    Explore reachable nodes, count components, find shortest hops.

    Builds on Graphs, Queues, Stacks, Graph algorithms.

  • Topological sort

    Order tasks so every dependency comes first.

    Builds on Graphs, Graph algorithms.

  • Union-Find

    Merge groups and ask whether two items are connected.

    Builds on Disjoint set (Union-Find), Graphs.

  • Shortest path

    Dijkstra, Bellman-Ford and 0-1 BFS on weighted graphs.

    Builds on Graphs, Heaps, Graph algorithms.

  • Trie

    Prefix search, autocomplete and word games.

    Builds on Trie.

  • Backtracking

    Subsets, permutations, combinations and constraint puzzles.

    Builds on Recursion, Backtracking.

  • 1D dynamic programming

    One index of state: stairs, robbers and decoding.

    Builds on Dynamic programming, Arrays.

  • 2D dynamic programming

    Grids and two-string problems like edit distance.

    Builds on Dynamic programming, Arrays.

  • Knapsack

    Choose items under a capacity: 0/1 and unbounded.

    Builds on Dynamic programming.

  • Interval DP

    Solve every subrange, shortest first.

    Builds on Dynamic programming.

  • Greedy

    Interval scheduling, jumps and gas stations.

    Builds on Greedy, Sorting, Heaps.

  • Bit manipulation

    XOR tricks, counting bits and subset masks.

    Builds on Bit manipulation.

  • Matrix traversal

    Spirals, rotations and flood fill on 2D grids.

    Builds on Arrays, Graphs.

  • Data structure design

    Build LRU caches, min stacks and iterators.

    Builds on Hash tables, Linked lists, Heaps.
