Shortest path

Weighted shortest-path problems are graph problems in disguise: delays on network links, flight prices, effort between grid cells. Pick the algorithm from two facts: are weights negative, and is there a limit on the number of edges?

Coding pattern

Picture it. Planning a train journey. Dijkstra is the planner that always extends the cheapest itinerary found so far. Bellman-Ford is the planner told "at most k changes", who improves every itinerary one leg at a time, k + 1 times.

Recognise it

  • Minimum time, cost or effort to reach one node or all nodes, with weights on the edges.
  • Grid problems where moving between cells has a cost that isn't always 1.
  • A limit on the number of steps or stops (Bellman-Ford with k rounds).
  • Weights of only 0 and 1: 0-1 BFS with a deque.

The template

Dijkstra (non-negative weights):
    dist[src] = 0; heap = [(0, src)]
    while heap: (d, u) = pop
        if d > dist[u]: continue                     ← stale entry
        for (v, w) in adj[u]:
            if d + w < dist[v]: dist[v] = d + w; push (dist[v], v)

Bellman-Ford with at most k edges:
    repeat k times: relax every edge using a copy of last round's distances

How it works

Both algorithms rest on relaxation: if reaching u and taking u → v is cheaper than the best known route to v, update v.

  • Dijkstra settles nodes in order of distance with a min-heap. It's the default for non-negative weights.
  • Bellman-Ford relaxes every edge in rounds. After round k, every path with at most k edges has been considered. Using a copy of the previous round's distances is what enforces the limit; without it, one round could chain several edges.
  • Minimax paths (like minimum effort, where a path costs its single worst step) use Dijkstra with max(d, w) in place of d + w.

The full algorithms, with Floyd-Warshall and minimum spanning trees, are on the Graph algorithms page.

Cost of each operation

OperationTimeWhy
Dijkstra with a heapO((V + E) log V)Each edge may push one heap entry.
Bellman-Ford limited to k edgesO(k × E)k rounds over all edges.
Grid Dijkstra (minimum effort)O(R × C × log(R × C))Each cell is a node with up to 4 edges.

Code

JavaScript and TypeScript include a small heap class, since neither language has one built in.

Common mistakes

  • Using Dijkstra when weights can be negative.
  • Updating Bellman-Ford distances in place when the number of stops is limited, which lets one round use several edges.
  • Forgetting the stale-entry check in Dijkstra.
  • Returning Infinity or MAX_VALUE instead of the problem's "unreachable" value (often −1).
