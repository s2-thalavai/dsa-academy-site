Bit manipulation

Interview bit problems reuse a handful of tricks: XOR cancels pairs, counting bits position by position, building an answer one bit at a time from the top, and doing arithmetic with AND, XOR and shifts.

Coding pattern

Picture it. Sorting socks in the dark by touch. XOR is like pairing them off: every pair cancels, and whatever is left in your hand is the odd sock out.

Recognise it

  • Every element appears twice (or three times) except one or two.
  • Reverse, count or compare the bits of a number.
  • Arithmetic without + or *.
  • Maximise an XOR: build the answer bit by bit from the most significant end.

The template

odd one out:         x = 0; for n in nums: x ^= n
appears three times: for each bit b: count the numbers with bit b set; keep bit b if count % 3 != 0
two odd ones out:    x = a ^ b; split nums by any set bit of x; XOR each group
max XOR:             for bit from high to low: try setting it, keep it if some prefix pair allows it

How it works

The operators and single-bit tricks are on the Bit manipulation technique page. These are the problem patterns built from them:

  • Single Number II (everything else appears three times): XOR can't cancel triples, but counting works. For each of the 32 bit positions, count how many numbers have it set; the unique number has that bit exactly when the count isn't a multiple of 3.
  • Single Number III (two unique numbers): XOR everything to get a ^ b. Any set bit in it is a position where a and b differ, so it splits the numbers into two groups with one unique number each.
  • Sum of two integers: XOR adds without carrying, AND then shift-left gives the carries. Repeat until there are no carries.
  • Maximum XOR of two numbers: decide the answer's bits from the top. For each bit, guess it's 1, then check with a set of prefixes whether two numbers can produce it (a ^ b = guess means a ^ guess is in the set).

Cost of each operation

OperationTimeWhy
Single Number (pairs)O(n) time, O(1) spaceOne XOR per element.
Single Number II (triples)O(32 × n)Count each bit position separately.
Reverse bitsO(32)One step per bit.
Maximum XOR of two numbersO(31 × n)One pass with a hash set per bit.

Code

Everything works on 32-bit values. Python masks with 0xFFFFFFFF to get the same results as Java and JavaScript.

Common mistakes

  • In Python, integers don't overflow, so emulating 32-bit arithmetic needs an explicit & 0xFFFFFFFF mask and a sign fix at the end.
  • In JavaScript, results above 2³¹ − 1 print as negative unless converted with >>> 0.
  • Forgetting parentheses around & in comparisons.
  • Shifting 1 << 31 in Java or JavaScript and getting a negative number.
