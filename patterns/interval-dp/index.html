Interval DP

Interval DP solves a problem for every contiguous range [i, j], building long ranges from shorter ones. It fits problems where the last action splits a range into two independent sides.

Coding pattern

Picture it. Cutting a long sausage into pieces at marked points, where each cut costs the length of the piece you're cutting. Whichever cut you make last splits the problem into a left piece and a right piece, each solved the same way.

Recognise it

  • The input is a sequence and the operation merges, splits or removes something inside a range.
  • The cost of an action depends on its neighbours, which change as elements are removed (burst balloons).
  • Palindromes over substrings: count them, find the longest, partition with fewest cuts.
  • n is up to a few hundred, which allows O(n³).

The template

for length from 1 to n:
    for i from 0 to n − length:
        j = i + length − 1
        dp[i][j] = best over split points k in [i, j] of
                   dp[i][k − 1] + dp[k + 1][j] + cost(i, j, k)
answer = dp[0][n − 1]

How it works

The trick in many interval problems is to choose the last action in the range, not the first. In burst balloons, the first balloon you burst changes everyone's neighbours, which makes subproblems depend on each other. But if balloon k is the last one burst in (i, j), its neighbours at that moment are exactly i and j, and the two sides (i, k) and (k, j) are independent.

Palindrome problems are interval DP with a simple transition: s[i..j] is a palindrome when s[i] == s[j] and s[i + 1..j − 1] is one.

Cost of each operation

OperationTimeWhy
General interval DPO(n³) time, O(n²) spaceO(n²) ranges × O(n) split points.
Palindromic substrings tableO(n²)Each range checks its inner range in O(1).

Code

Every table is filled by increasing range length, so each cell only reads cells already computed.

Common mistakes

  • Iterating i and j in plain nested loops instead of by length, so a range reads unfinished subranges.
  • Choosing the first action instead of the last, which makes the subproblems depend on each other.
  • Forgetting to pad the array (burst balloons adds a 1 at each end) or to include the stick ends among the cut points.
