Union-Find

When a problem keeps merging groups and asking whether two items share a group, a disjoint set union answers both in near-constant time. Each edge either joins two groups or, if both ends were already together, closes a cycle.

Coding pattern

Picture it. Friends of friends at a party. Each new introduction merges two friend circles. To check whether two guests are connected, you don't trace every introduction; you ask each who the "host" of their circle is.

Recognise it

  • Counting connected groups: provinces, components, islands that appear one cell at a time.
  • Finding the edge that creates a cycle in an undirected graph.
  • Grouping items that are equivalent through a chain (same email, similar strings, equal variables).
  • Kruskal's minimum spanning tree.

The template

dsu = n separate groups
for each relation (a, b):
    if find(a) == find(b): a and b were already connected (this edge closes a cycle)
    else: union(a, b)
answer from dsu.groups, find() results, or the cycle edge

How it works

The data structure itself is on its own page: Disjoint set (Union-Find). The pattern is recognising when the question is secretly "merge, then ask who's together", and choosing what the items are.

  • Number of provinces: items are cities; each 1 in the matrix is a union. The answer is the number of groups left.
  • Redundant connection: process edges in order; the first edge whose ends already share a root is the extra one.
  • Path exists: union every edge, then compare two roots.

Union-find shines when edges arrive over time. If you have the whole graph up front and need only one answer, BFS or DFS works just as well.

Cost of each operation

OperationTimeWhy
Each find or unionO(α(n)) amortisedWith path compression (or halving) and union by size.
Process E edges over n itemsO(n + E × α(n))Effectively linear.

Code

All three problems share the same small DSU class with path halving and union by size.

Common mistakes

  • Comparing parents instead of roots: always call find.
  • Off-by-one with 1-based node labels; size the arrays n + 1 or subtract 1.
  • Decrementing the group count when a union finds the two items already together.
