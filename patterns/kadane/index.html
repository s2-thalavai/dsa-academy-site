Kadane's algorithm

Kadane's algorithm finds the best subarray in one pass by tracking one number: the best sum of a subarray that ends right here. Either extend the previous best, or start fresh at the current element.

Coding pattern

Picture it. A running profit tally on a road trip. At each town you ask: is my tally from earlier towns helping or hurting? If it's negative, you'd do better to forget it and start counting from this town.

Recognise it

  • Maximum (or minimum) sum or product of a contiguous subarray.
  • Best single buy-and-sell, or any "best gain between an earlier and a later point".
  • A brute force would try every start and end: O(n²).

The template

bestEndingHere = a[0], best = a[0]
for i from 1 to n − 1:
    bestEndingHere = max(a[i], bestEndingHere + a[i])   ← start fresh or extend
    best = max(best, bestEndingHere)

How it works

Every subarray ends somewhere. If you know the best sum of a subarray ending at i − 1, the best ending at i is either that plus a[i], or just a[i] alone (when the earlier part is negative and only drags it down). Taking the maximum of those over all i gives the answer.

That makes Kadane a tiny dynamic programming solution with O(1) state. Variations change the state:

  • Maximum product: track both the largest and the smallest product ending here, because multiplying by a negative swaps them.
  • Circular array: the best wrap-around subarray is the total minus the minimum subarray. Take the larger of the two (unless every number is negative).
  • Best time to buy and sell: track the lowest price so far; the best profit today is today's price minus it.

Cost of each operation

OperationTimeWhy
Maximum subarray sumO(n) time, O(1) spaceOne pass, two variables.
Maximum product subarrayO(n) time, O(1) spaceTrack the current maximum and minimum.
Circular maximumO(n)Run Kadane for both the maximum and the minimum in the same pass.

Code

maxSubarray also returns where the best subarray starts and ends, by remembering the index where the current run began.

Common mistakes

  • Initialising best to 0, which returns 0 for an all-negative array instead of the largest element.
  • In maximum product, forgetting the minimum, so a negative times a negative is missed.
  • In the circular version, returning total − minSubarray when all numbers are negative (it would be 0, an empty subarray).
