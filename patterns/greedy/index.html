Greedy

These problems are solved by one sort and one pass, making the locally best choice each time. The work is in finding the right greedy rule and convincing yourself it can't backfire.

Coding pattern

Picture it. Handing out tickets for a concert to people queueing with different minimum seat needs. Give the smallest suitable seat to the least demanding person first. Wasting a big seat on someone who'd be happy with a small one can only make things worse later.

Recognise it

  • Intervals: remove the fewest to stop overlaps, shoot the fewest arrows, schedule the most meetings.
  • Matching two sorted lists (cookies to children, boats to people).
  • "Minimum jumps", "can you complete the circuit?", running balances that must stay non-negative.
  • The problem gets easy once the input is sorted by the right key.

The template

sort by the key that makes the greedy choice safe (often the end time)
state = initial
for each item in order:
    if taking it keeps the solution valid: take it, update state
    else: skip it (count it as removed, start a new group, …)

How it works

The technique and its proof style (the exchange argument) are on the Greedy technique page. Here are the rules for the common problem shapes:

  • Non-overlapping intervals: sort by end; keep an interval if it starts at or after the last kept end; everything else must be removed.
  • Minimum arrows: sort by end; one arrow at the current end bursts every balloon that starts before it.
  • Jump game II: treat it as BFS by ranges. Track the furthest reach of the current "level"; when you pass the level's end, you need another jump.
  • Gas station: if the total gas is at least the total cost, a start exists. Whenever the running tank goes negative, no station up to here can be the start, so try the next one.
  • Candy: two passes. Left to right gives each child more than a lower-rated left neighbour; right to left fixes the right neighbours.

Cost of each operation

OperationTimeWhy
Interval greedyO(n log n)Sort, then one pass.
Jump game II, gas stationO(n) time, O(1) spaceOne pass with a couple of counters.
CandyO(n) time, O(n) spaceTwo passes over an array of candy counts.

Code

Each function is a sort (when needed) followed by a single pass.

Common mistakes

  • Sorting intervals by start when the rule needs end order.
  • In jump game II, counting a jump when you reach the last index rather than when you leave a range.
  • In gas station, resetting the tank but forgetting to move the candidate start to the next station.
  • Assuming the greedy rule without testing a small counterexample.
