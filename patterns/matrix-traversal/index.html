Matrix traversal

Matrix problems are about walking a 2D grid in a particular order, or transforming it in place. Most come down to careful index bookkeeping: four boundaries for a spiral, a transpose plus a reversal for rotation, a corner to start from for searching.

Coding pattern

Picture it. Reading a page in a spiral, peeling an onion layer by layer, or turning a photo on a table by a quarter turn. Each is simple once you decide what changes with every step.

Recognise it

  • Spiral order, diagonal order, zigzag order over a matrix.
  • Rotate, transpose, flip or reflect a matrix, often in place.
  • Mark rows and columns (set matrix zeroes) or compute the next state of every cell (game of life) without extra memory.
  • Search a matrix sorted along rows and columns.

The template

spiral:  top, bottom, left, right = edges
         while top <= bottom and left <= right:
             read the top row, then top += 1
             read the right column, then right −= 1
             if top <= bottom: read the bottom row backwards, bottom −= 1
             if left <= right: read the left column upwards, left += 1
rotate:  transpose (swap m[i][j] and m[j][i] for j > i), then reverse every row
search:  start at the top-right; too big → move left, too small → move down

How it works

  • Spiral order: the two if checks stop the last row or column from being read twice when the matrix isn't square.
  • Rotate 90° clockwise in place: a transpose swaps rows and columns, and reversing each row then mirrors it left to right. Counter-clockwise reverses rows first (or columns after).
  • Set matrix zeroes in O(1) space: use the first row and first column as markers for which columns and rows to clear, plus one flag each for whether the first row and column themselves need clearing.
  • Search a row- and column-sorted matrix: from the top-right corner, every step either moves left (the value is too big, so the whole column below is too big) or down (too small, so the whole row to the left is too small). That's at most rows + cols steps.

Cost of each operation

OperationTimeWhy
Spiral, transpose, rotateO(R × C)Every cell is read or moved once.
Set matrix zeroes in placeO(R × C) time, O(1) spaceFirst row and column store the markers.
Staircase searchO(R + C)Each step removes a row or a column.

Code

Matrices print row by row, separated by slashes.

Common mistakes

  • Reading the last row or column twice in spiral order for non-square matrices.
  • Transposing by looping over all (i, j) instead of j > i, which swaps every pair twice and undoes itself.
  • Clearing cells while still scanning for zeroes, which turns new cells into zeroes and spreads.
  • Mixing up rows and columns for non-square matrices (m[r][c] with r < rows, c < cols).
