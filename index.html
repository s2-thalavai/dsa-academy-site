A visual course on data structures, algorithms, coding patterns and low-level design, for engineers getting ready for interviews. Every concept comes with a diagram, a step-by-step animation and runnable code in Java, JavaScript, TypeScript and Python.

Five parts, one path through them

  • Data structures10 structures, each drawn as it sits in memory, from arrays to union-find.
  • Algorithms12 techniques with a template you can reuse and a test for when it applies.
  • Coding patterns31 patterns, each with 3 to 5 solved LeetCode problems from easy to hard.
  • Low-level design17 designs, most of them concurrent, with class and sequence diagrams.
  • PracticeEvery problem on the site in one list you can filter by pattern, structure and difficulty.

Every concept page reads the same way

  1. ExplanationPlain English and a concrete example before any theory.
  2. PictureA labelled diagram, including how the data sits in memory.
  3. AnimationStep through it, change the speed, or feed it your own input.
  4. CodeRunnable in Java, JavaScript, TypeScript and Python, with expected output.
  5. PracticeProblems to try next, linked to LeetCode.
