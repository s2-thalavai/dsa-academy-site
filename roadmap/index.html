Course roadmap

10 stages, 70 topics, about 24 weeks at 8 to 10 hours a week. Each topic lists what it needs, and every prerequisite comes earlier on the page.

0 of 70 topics done

Next up: Complexity analysis

Progress is saved in this browser only.

  1. 1

    Foundations

    Weeks 1–2 · 3 topics

    Read code for its cost, and get comfortable with arrays and recursion.

    • Complexity analysis Technique

      Big-O, Big-Θ, Big-Ω and amortised cost, with worked examples.

    • Arrays Structure

      Contiguous memory, O(1) indexing, 2D layouts, dynamic resizing and strings. Needs Complexity analysis.

    • Recursion Technique

      Base cases, the call stack and how to trust the recursive call. Needs Complexity analysis.

  2. 2

    Linear structures

    Weeks 3–4 · 4 topics

    Know the four structures every other topic is built from.

    • Linked lists Structure

      Nodes scattered in memory joined by pointers; singly, doubly and circular. Needs Arrays.

    • Stacks Structure

      Last in, first out. The call stack, recursion and expression evaluation. Needs Arrays, Recursion.

    • Queues Structure

      First in, first out. Circular buffers, deques and priority queues. Needs Arrays.

    • Hash tables Structure

      Hash functions, buckets, collisions, load factor and resizing. Needs Arrays.

  3. 3

    Array and list patterns

    Weeks 5–7 · 8 topics

    Solve most easy and medium array questions in O(n).

    • Two pointers Pattern

      Two indices walk the data toward each other or in step. Needs Arrays.

    • Sliding window Pattern

      Grow and shrink a contiguous range instead of rescanning it. Needs Two pointers, Hash tables.

    • Prefix sum Pattern

      Precompute running totals so any range sum is one subtraction. Needs Arrays, Hash tables.

    • Hashing Pattern

      Trade memory for O(1) lookups of what you've already seen. Needs Hash tables.

    • Kadane's algorithm Pattern

      Best subarray ending here, carried forward in O(1) space. Needs Arrays.

    • Cyclic sort Pattern

      Place each number 1..n at its own index in one pass. Needs Arrays.

    • Fast and slow pointers Pattern

      Two speeds detect cycles and find middles. Needs Linked lists.

    • In-place list reversal Pattern

      Reverse links in place with three pointers. Needs Linked lists.

  4. 4

    Searching and sorting

    Weeks 8–9 · 5 topics

    Pick the right sort, and bend binary search to new problems.

    • Searching Technique

      Linear search, binary search and binary search on the answer. Needs Arrays.

    • Sorting Technique

      Eight sorts compared side by side, with stability explained. Needs Arrays, Recursion.

    • Divide and conquer Technique

      Split, solve the halves, combine. Merge sort and beyond. Needs Sorting.

    • Modified binary search Pattern

      Binary search on rotated arrays, boundaries and answers. Needs Searching.

    • Merge intervals Pattern

      Sort by start, then merge or count overlaps. Needs Sorting.

  5. 5

    Stack and queue patterns

    Weeks 10 · 2 topics

    Answer "next greater" and "window max" questions in linear time.

    • Monotonic stack Pattern

      Keep a sorted stack to find the next greater or smaller element. Needs Stacks.

    • Monotonic deque Pattern

      Window maximum or minimum in O(n). Needs Queues, Sliding window.

  6. 6

    Trees and heaps

    Weeks 11–13 · 9 topics

    Traverse any tree, and use heaps for ranking and merging.

    • Trees Structure

      Binary trees, BSTs, balanced trees, traversals, segment and Fenwick trees. Needs Recursion, Queues.

    • Tree DFS Pattern

      Pre, in and post order, and passing state down or up. Needs Trees.

    • Tree BFS Pattern

      Level by level with a queue. Needs Trees.

    • Heaps Structure

      A tree stored in an array. Sift up, sift down and O(n) heapify. Needs Trees.

    • Top K elements Pattern

      A size-K heap keeps the best K seen so far. Needs Heaps.

    • Two heaps Pattern

      A max-heap and a min-heap split the data at the median. Needs Heaps.

    • K-way merge Pattern

      Merge K sorted inputs using a heap of their heads. Needs Heaps, Linked lists.

    • Trie StructureAdvanced

      A tree of characters for fast prefix lookups. Needs Trees, Hash tables.

    • Trie Pattern

      Prefix search, autocomplete and word games. Needs Trie.

  7. 7

    Graphs

    Weeks 14–16 · 8 topics

    Model a problem as a graph, then choose the right traversal.

    • Graphs Structure

      Adjacency lists and matrices, grids as graphs, DAGs. Needs Hash tables, Queues.

    • Graph algorithms Technique

      BFS, DFS, topological sort, Dijkstra, Bellman-Ford, Floyd-Warshall, Prim, Kruskal. Needs Graphs, Heaps.

    • Graph BFS and DFS Pattern

      Explore reachable nodes, count components, find shortest hops. Needs Graphs.

    • Matrix traversal Pattern

      Spirals, rotations and flood fill on 2D grids. Needs Graph BFS and DFS.

    • Topological sort Pattern

      Order tasks so every dependency comes first. Needs Graph BFS and DFS.

    • Disjoint set (Union-Find) StructureAdvanced

      Track groups that merge, with path compression and union by rank. Needs Arrays.

    • Union-Find Pattern

      Merge groups and ask whether two items are connected. Needs Disjoint set (Union-Find), Graphs.

    • Shortest path Pattern

      Dijkstra, Bellman-Ford and 0-1 BFS on weighted graphs. Needs Graph algorithms.

  8. 8

    Backtracking, greedy and DP

    Weeks 17–20 · 9 topics

    Turn a brute-force search into a fast solution.

    • Backtracking Technique

      Build a candidate step by step and undo when it can't work. Needs Recursion.

    • Backtracking Pattern

      Subsets, permutations, combinations and constraint puzzles. Needs Backtracking.

    • Greedy Technique

      Take the best local choice, and prove it never hurts later. Needs Sorting.

    • Greedy Pattern

      Interval scheduling, jumps and gas stations. Needs Greedy, Heaps.

    • Dynamic programming Technique

      Memoisation and tabulation across 1D, 2D, knapsack, interval and string DP. Needs Recursion, Hash tables.

    • 1D dynamic programming Pattern

      One index of state: stairs, robbers and decoding. Needs Dynamic programming.

    • 2D dynamic programming Pattern

      Grids and two-string problems like edit distance. Needs 1D dynamic programming.

    • Knapsack Pattern

      Choose items under a capacity: 0/1 and unbounded. Needs 2D dynamic programming.

    • Interval DP Pattern

      Solve every subrange, shortest first. Needs 2D dynamic programming.

  9. 9

    Specialist topics

    Weeks 21 · 5 topics

    Cover the tricks that show up in a minority of questions but cost a lot if missed.

    • Bit manipulation Technique

      Masks, shifts and the tricks that turn loops into one operation. Needs Complexity analysis.

    • Bit manipulation Pattern

      XOR tricks, counting bits and subset masks. Needs Bit manipulation.

    • Math basics Technique

      GCD, primes and the sieve, modular arithmetic, fast power. Needs Complexity analysis.

    • String algorithms Technique

      KMP, Rabin-Karp and an overview of the Z-algorithm. Needs Arrays, Hash tables.

    • Data structure design Pattern

      Build LRU caches, min stacks and iterators. Needs Hash tables, Linked lists, Heaps.

  10. 10

    Low-level design

    Weeks 22–24 · 17 topics

    Design classes that hold up under concurrency, and explain why.

    • LLD fundamentals Design

      SOLID, key design patterns and Java concurrency primitives.

    • Bounded blocking queue Design

      Producer–consumer with locks and conditions. Needs LLD fundamentals, Queues.

    • Rate limiter Design

      Token bucket and sliding window, safe under many threads. Needs LLD fundamentals.

    • Thread-safe LRU cache Design

      Hash map plus linked list behind a lock strategy. Needs LLD fundamentals, Data structure design.

    • Thread pool and scheduler Design

      Workers, a task queue, delayed and periodic tasks. Needs Bounded blocking queue.

    • Parking lot Design

      Concurrent entry and exit gates competing for spots. Needs LLD fundamentals.

    • Movie ticket booking Design

      Seat locks with timeouts so two people never buy one seat. Needs LLD fundamentals.

    • Pub-sub message queue Design

      Topics, offsets and multiple consumers. Needs Bounded blocking queue.

    • Read-write lock and KV store Design

      Many readers, one writer, no starvation. Needs LLD fundamentals.

    • Elevator system Design

      Several elevators and a dispatcher deciding who goes where. Needs LLD fundamentals.

    • Snowflake IDs and a thread-safe logger Design

      Unique IDs without coordination; logs that don't interleave. Needs LLD fundamentals.

    • Synchronisation puzzles Design

      Print in Order, FooBar, H2O, Fizz Buzz, Dining Philosophers, Web Crawler. Needs LLD fundamentals.

    • Splitwise Design

      Expenses, splits and simplified balances. Needs LLD fundamentals.

    • Snake and ladder Design

      Board, players, dice and turn order. Needs LLD fundamentals.

    • Library management Design

      Members, loans, reservations and fines. Needs LLD fundamentals.

    • Vending machine Design

      The State pattern, one state per mode. Needs LLD fundamentals.

    • Logging framework Design

      Chain of Responsibility across log levels and sinks. Needs LLD fundamentals.
